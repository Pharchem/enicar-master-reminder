How to add a Report Link

When a task's report/record is filed, attach a link to it on the dashboard. That way QA and the Director can open and verify the report in one click. It takes about 30 seconds.

  1. Put the report file online (skip if it already is)

    Save the report PDF / Word file / scan to Google Drive (or your usual shared folder). If the report is already an email attachment or a file in Drive, use that.

    Paper-only record with a wet signature? See the note at the bottom.

  2. Copy a shareable link

    In Google Drive: right-click the file → Share. Under General access choose "Anyone with the link" and role Viewer, then click Copy link.

    "Anyone with the link" means anyone who has the (unguessable) link can view it — it is not listed publicly. Viewer = they can read, not edit.

  3. Open the task on the dashboard

    Go to the dashboard, pick your department, and find the task (use the Search box — type the equipment ID or name). Tap ✓ Report done.

  4. Sign in if asked

    Enter your department password and your name. You stay signed in for 1 hour, so you can do several at once.

  5. Paste the link and save

    Paste the copied link into the Report link box, then tap Mark report done.

  6. Done — the report is now attached

    The task shows a green 📎 View report button. Anyone can click it to open the actual report. Reminder emails for that task stop.

No electronic file (paper record only)? You can still tap "Report done" without a link — the task will show "no report link", and QA will verify against the physical file. The link is optional; it is just the easiest way for others to see the report without asking.
